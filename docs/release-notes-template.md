{{SUMMARY}}

## Download

Download `scribetray-v{{VERSION}}-x86_64.zip` and `SHA256SUMS.txt`, then
extract `scribetray.exe`. The checksum file covers both the ZIP and standalone
executable attached to this release.

## Security

Download the files from this GitHub release and verify the executable or ZIP
SHA-256 against `SHA256SUMS.txt` before running it. The executable is not code
signed yet, so Windows SmartScreen may show a warning on first launch.
