The drawing code in this page is the reference for the Rust overlay (see PLAN.md). All geometry is in DIPs and multiplied by the monitor scale. Waveform bars come from real input level: the audio thread publishes an RMS envelope and the UI samples it every 50 ms, so flat bars mean the mic is not hearing you.
